You are designing and implementing the authentication flow UI for a modern cross-platform application built with React Native + React Native Reanimated. The application supports Android, iOS, and web from a single shared codebase.

The authentication system currently contains multiple auth-related pages and navigation already exists. You must preserve and integrate with the existing navigation structure instead of replacing it.

---

## GENERAL DESIGN GOALS

The auth experience must:

* feel modern, premium, and responsive
* avoid empty desktop layouts
* work beautifully on mobile and web
* share the same architecture across platforms
* support light and dark themes cleanly
* feel native on mobile and professional on desktop
* use smooth but subtle animations
* preserve existing navigation flow and auth routing

Use:

* React Native
* React Native Reanimated
* responsive layouts
* existing theme system
* existing navigation stack

Do NOT:

* create separate mobile/web pages
* use fixed desktop-only layouts
* stretch forms excessively wide
* create visually empty desktop screens
* break existing auth navigation

---

## AUTH FLOW STRUCTURE

After the splash screen, introduce a new auth selection screen before login/signup.

Flow:

Splash Screen
↓
Role Selection Screen
↓
Candidate Auth Flow OR Company Auth Flow
↓
Existing Login / Signup / Forgot Password Screens

The role selection screen must integrate into the current auth navigation architecture cleanly.

---

---

* Continue as Candidate

This screen must NOT look empty on desktop.

## DESKTOP/TABLET LAYOUT

Use a split-screen responsive layout.

LEFT SECTION:

* visually rich panel
* fills empty space intentionally
* can contain:

  * abstract gradient background
  * illustration
  * dashboard preview
  * branding
  * subtle animated blobs/shapes
  * feature highlights
* should adapt to dark/light theme
* should feel modern SaaS-like

RIGHT SECTION:

* centered selection card
* constrained width (~420-500px max)
* contains:

  * app logo
  * heading
  * short subtitle
  * role selection buttons/cards
  * navigation actions

* contains role selection UI
* rounded top corners
* elevated appearance
* should feel app-native

## THEMING

The entire auth system must support:

* light theme
* dark theme
* animated transitions between themes

Theme changes should affect:

* backgrounds
* gradients
* cards
* text
* borders
* overlays
* illustrations where applicable

Dark mode should:

* feel premium
* use layered surfaces
* avoid flat black backgrounds

Light mode should:

* use subtle tinted backgrounds
* maintain depth separation

---

## ANIMATIONS

Use Reanimated for subtle motion only.

Recommended:

* card entrance animation
* fade/slide transitions
* gradient transitions
* hover/press feedback
* floating background motion

Avoid:

* excessive motion
* distracting parallax
* overly complex transitions

Animations should feel smooth and premium.

* work properly on Android/iOS/web

* adapt fluidly
* preserve accessibility

Avoid:

* platform-specific duplicated layouts
* hardcoded screen assumptions
